# Vivo Esporte

## Tema
Site sobre esporte, saúde e bem-estar, com foco em incentivar a prática de atividades físicas e mostrar diferentes modalidades.

## Objetivo
Apresentar informações sobre esportes, benefícios do exercício físico, modalidades populares e espaço para contato com os visitantes.

## Páginas do site
- index.html
- sobre.html
- informacoes.html
- contato.html

## Tecnologias utilizadas
- HTML5
- CSS3
- Bootstrap 5
- Google Fonts
- Git e GitHub

## Componentes Bootstrap usados
- Navbar
- Cards
- Botões
- Tabela
- Formulário
